What happens next

  1. Review and edit the name, context, date and note in Jumpa.
  2. Choose an existing demo person or create a new demo person. No automatic matching.
  3. Tap Save to demo people, or cancel without adding an encounter.

Only Jumpa's separate fictional demo dataset can receive this test. Real people and your current demo/real display setting stay unchanged. Turn demo on in Jumpa to view the saved note. Reopening the same sample will not add it again.

An invitation is not proof that someone attended. The preview keeps arrival context separate from a confirmed meeting. No chat is sent, no phone contact is edited, and nothing syncs automatically.

What this is not

Kunjung still has no live inbox. This page does not connect to Delta Chat, read contacts, create groups or carry real invite tokens. It sends only a fixed demo identifier, not editable personal data in a URL. Jumpa's affiliations, notes, promises and contact picker stay available as before.
